## Delivery Boundary

::: info Responsibility Scope
Chinasofti supports integration with third-party eKYC services and has hands-on experience with major vendors. If the client provides their own eKYC vendor, Chinasofti delivers the client-side entry point, process orchestration, and API integration; OCR, face recognition, liveness detection, and ID-face matching algorithms are guaranteed by the client's vendor.
:::
