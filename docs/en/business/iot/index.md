## Key Dependencies / Prerequisites

::: warning Confirm the following before project kickoff
- Device-side protocols and gateway
- Device lifecycle management
- Data compliance requirements
- On-site operations and maintenance capability
:::

## Delivery Approach

::: tip Delivery Notes
Integrates with Tuya IoT for device onboarding, management, and data synchronization; delivers device control frontend (e.g. "My Smart Home" panel)
:::

## Delivery Boundary

::: info Responsibility Scope
Chinasofti provides the device onboarding and management platform. Device procurement, on-site installation, and field maintenance are the responsibility of the client or ecosystem partners.
:::
