## Key Dependencies / Prerequisites

::: warning Confirm the following before project kickoff
- Ticketing supplier / aggregator API
- Real-name verification and risk control
- Refund and change-of-date rules
- Seat map / 3D view (optional)
:::

## Delivery Approach

::: tip Delivery Notes
Integration with ticketing suppliers / aggregator platforms (ticket orders and payment)
:::

## Delivery Boundary

::: info Responsibility Scope
Chinasofti provides aggregated ticket access and order payment. Ticket inventory and refund/exchange handling are the responsibility of the ticketing supplier.
:::
