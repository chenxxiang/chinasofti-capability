## Key Dependencies / Prerequisites

::: warning Confirm the following before project kickoff
- Charging operator / pile manufacturer protocol (OCPP, etc.)
- Billing rules
- Payment and settlement
- Map and location services
:::

## Delivery Approach

::: tip Delivery Notes
Integration with third-party charging operations platform; covers start/stop session, billing orders, and wallet statement
:::

## Delivery Boundary

::: info Responsibility Scope
Chinasofti is responsible for charging platform API integration and business flow. Charging operations, pile-side maintenance, and on-site services are the responsibility of the charging operator.
:::
