## Key Dependencies / Prerequisites

::: warning Confirm the following before project kickoff
- Transit card issuance / clearing system
- NFC / QR code capability
- Real-name verification and risk control
- Terminal hardware upgrade status
:::

## Delivery Approach

::: tip Delivery Notes
Transit QR-code integration + fare deduction + reconciliation + billing statement
:::

## Delivery Boundary

::: info Responsibility Scope
Chinasofti provides the transit card account / virtual card entry point and fare deduction integration. Offline gate / vehicle terminal hardware is the responsibility of the transit authority.
:::
