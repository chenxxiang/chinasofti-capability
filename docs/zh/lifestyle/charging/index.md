## 关键依赖 / 前置条件

::: warning 启动前需确认以下条件就绪
- 充电运营方/桩厂协议(OCPP等)

- 支付/结算
- 地图与定位
:::

## 中软交付方式

::: tip 交付说明
对接第三方充电运营平台/桩平台，完成启停会话、计费订单与钱包账单集成
:::

## 交付边界

::: info 责任划分
CSI 负责充电平台接口对接与业务链路集成；充电运营、桩侧运维及线下服务由充电运营方负责
:::
