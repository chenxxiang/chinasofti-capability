## 关键依赖 / 前置条件

::: warning 启动前需确认以下条件就绪
- 交通卡发行/清分系统
- NFC/QR能力
- 实名与风控
- 终端改造情况
:::

## 中软交付方式

::: tip 交付说明
乘车码集成+扣费对接+对账处理+账单接入
:::

## 交付边界

::: info 责任划分
提供交通卡账户/虚拟卡入口与扣费对接；线下闸机/车载终端由交通方负责
:::

## 应用场景

2. **地铁**
