## 中软交付方式

::: tip 交付说明
集成成熟算法供应商提供端到端交付
:::

## 交付边界

::: info 责任划分
支持集成第三方 eKYC 服务，已具备对接供应商的实施经验；若ekcy供应商由客户提供，CSI 提供客户端入口与流程编排及接口集成，OCR/人脸识别/活体检测/人证比对等算法能力由客户侧保障
:::

## 应用场景

1. **刷脸支付**
2. **活体检测**
3. **人证比对**
4. **证件识别**
