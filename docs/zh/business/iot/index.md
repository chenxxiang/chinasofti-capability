## 关键依赖 / 前置条件

::: warning 启动前需确认以下条件就绪
- 设备侧协议与网关
- 设备生命周期管理
- 数据合规
- 现场运维能力
:::

## 中软交付方式

::: tip 交付说明
对接 Tuya（涂鸦）IoT，实现设备接入/管理/数据同步，并交付设备控制前端（如“我的e家”面板）
:::

## 交付边界

::: info 责任划分
提供设备接入与管理平台；设备供货、现场安装与运维由客户/生态伙伴负责
:::

## 应用场景

1. **智能家居（电灯、电器、窗帘等）**
2. **智能楼宇**
3. **智能体育馆**
