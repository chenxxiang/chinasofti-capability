## 关键依赖 / 前置条件

::: warning 启动前需确认以下条件就绪
- 提供现有应用的页面清单与迁移范围确认
- 对应业务系统 API 接口文档与联调环境
- 以及小程序平台的开发/发布访问权限（开发者账号
- 测试/预生产/生产发布权限）
:::

## 中软交付方式

::: tip 交付说明
MiniProgram 迁移适配 + 联调测试 + 上架发布
:::

## 交付边界

::: info 责任划分
CSI 负责将既有应用按确认范围改造成小程序（页面重构/适配、接口联调、基础埋点适配），完成测试并提交上架；小程序平台运行环境、发布审核、账号权限、以及平台侧稳定性与合规治理由客户/平台方负责。
:::
