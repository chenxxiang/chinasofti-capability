# 中软国际能力库

VitePress documentation site for ChinaSofti Mini-App capabilities.

## Development

```bash
npm install
npm run docs:dev
```

## Adding Content

- Chinese pages: `docs/zh/`
- English pages: `docs/en/`
- Images: `public/`

Each `.md` file corresponds to one page in the sidebar.

## Deployment

Push to `main` branch → Vercel auto-deploys.
